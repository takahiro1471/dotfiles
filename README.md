# Dotfiles
## 初回セットアップ
1. chezmoiをインストールし、このリポジトリをダウンロードする  
\# Linux / macOS  
`mkdir -p ~/.local/bin && cd ~/.local/bin && sh -c "$(curl -fsLS https://get.chezmoi.io)" -- -b . init --apply takahiro1471`  
\# Windows(PowerShell)  
`irm https://get.chezmoi.io/ps1 | iex; chezmoi init --apply takahiro1471`
